## Deviations from §10.4, stated

1. **One fresh sandbox per claude arm**, where §10.4 has a single "S2". Session state the CLI creates on its first run would already exist when A-cwd runs, which could hide the exact write A-cwd is meant to detect. Production uses a fresh sandbox per attempt (A-O2-12).
2. The claude arms use the **no-bundle, no-MCP-config** literal, which is the production default while the Unit C tool surface is off. S-P1 stages the full set (prompt, instructions and MCP config), as §10.4 asks.
3. Classification: changed paths under `~/.claude*`, `~/.config`, `~/.cache`, `~/.npm` and `~/.local` are reported as `cli-home-state` and are not counted as cwd writes. Every changed path is still recorded, with the prefix list, so the record can be reclassified.
