# CI Phase 1.1 — Aggregator Gate + Docs Path-Skip + Governance — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make branch protection require a single computed gate (`ci-required`) instead of 5 individual job checks, so conditional execution becomes safe — then use that to skip the heavy suite on docs-only PRs (fast docs) and add required human review + CODEOWNERS (governance).

**Architecture:** Introduce a cheap `changes` job that detects whether any non-doc file changed, gate the heavy jobs on `changes.code == true` (and not-draft), and add an always-running `ci-required` aggregator that computes pass/fail explicitly from `needs.*.result`. Branch protection then requires only `ci-required`, which neutralizes GitHub's "skipped required check = passing" footgun (the Phase 1 P1). Add `.github/CODEOWNERS` + required reviews. Design approved via brainstorming 2026-06-24. Builds on Phase 1 ([2026-06-24-ci-trigger-redesign-plan.md](2026-06-24-ci-trigger-redesign-plan.md)).

**Tech Stack:** GitHub Actions YAML, `gh` CLI / GitHub REST API (branch protection — admin), `rg` + `python -c "import yaml"` for verification.

## Approved Design (reference)

**Job graph (new `pr.yml`):**

```
changes        cheap; always runs (skips on draft). Diffs base…head → outputs code=true|false
policy         always runs (skips on draft) — unchanged from Phase 1
brand-check    always runs (skips on draft) — unchanged from Phase 1
verify         needs: changes; runs iff code==true AND not-draft
e2e            needs: changes; runs iff code==true AND not-draft
migrations     needs: changes; runs iff code==true AND not-draft
verify-cross-platform / e2e-cross-platform   same gate; stay advisory (continue-on-error)
ci-required    needs: [changes, policy, brand-check, verify, e2e, migrations];
               runs unless cancelled and not-draft; computes the verdict
```

**`not-draft`** everywhere means: `(github.event_name != 'pull_request' || !github.event.pull_request.draft)`.

**`ci-required` verdict (the keystone):** fail if `changes` did not succeed, or if any of `policy/brand-check/verify/e2e/migrations` reported `failure`/`cancelled`. A `skipped` heavy job (docs-only PR) is allowed. Because the verdict is computed, a skipped required check can no longer silently pass.

**Docs skip-set:** a PR is "docs-only" (heavy jobs skip) iff **every** changed file matches `^docs/` or `\.md$`. Anything else (incl. `.github/**`, `package.json`, any `src`) ⇒ `code=true` ⇒ full CI. Conservative: any doubt runs full CI.

**Governance:** require 1 approving review on `main` + `require_code_owner_reviews`; `.github/CODEOWNERS` mandates review for `.github/**` (CI) and `packages/db/**` (migrations).

**Out of scope → Phase 1.2:** GitHub Merge Queue (the retarget/staleness answer). Retarget stays "push to re-trigger," already documented in `AGENTS.md`/`CLAUDE.md`. Do NOT re-add `edited` (Phase 1 P1).

## Task 1: Add the `changes` detection job

**Files:**
- Modify: `.github/workflows/pr.yml` (add a new job at the top of `jobs:`, before `policy`)

- [ ] **Step 1: Add the `changes` job**

Insert this as the first job under `jobs:` (immediately after the `jobs:` line, before `policy:`):

```yaml
  # Cheap change-detector: decides whether the heavy suite needs to run.
  # A PR is "docs-only" (code=false) iff EVERY changed file is under docs/
  # or ends in .md. Anything else (.github/**, package.json, src, etc.) =>
  # code=true => full CI. On push (main) code is always true.
  changes:
    runs-on: ubuntu-latest
    if: ${{ github.event_name != 'pull_request' || !github.event.pull_request.draft }}
    timeout-minutes: 5
    outputs:
      code: ${{ steps.detect.outputs.code }}
    steps:
      - name: Checkout repository
        uses: actions/checkout@34e114876b0b11c390a56381ad16ebd13914f8d5 # v4.3.1
        with:
          fetch-depth: 0
      - name: Detect non-doc changes
        id: detect
        run: |
          if [ "${{ github.event_name }}" != "pull_request" ]; then
            echo "code=true" >> "$GITHUB_OUTPUT"
            echo "push event -> code=true"
            exit 0
          fi
          changed="$(git diff --name-only "${{ github.event.pull_request.base.sha }}...${{ github.event.pull_request.head.sha }}")"
          if [ -z "$changed" ]; then
            echo "code=true" >> "$GITHUB_OUTPUT"
            echo "empty diff -> code=true (fail safe)"
            exit 0
          fi
          # Non-doc = NOT under docs/ AND NOT ending in .md
          nondoc="$(printf '%s\n' "$changed" | grep -Ev '^docs/|\.md$' || true)"
          if [ -n "$nondoc" ]; then
            echo "code=true" >> "$GITHUB_OUTPUT"
            echo "non-doc files changed -> code=true:"
            printf '%s\n' "$nondoc"
          else
            echo "code=false" >> "$GITHUB_OUTPUT"
            echo "docs-only change -> code=false; heavy suite will skip"
          fi
```

## Task 3: Add the `ci-required` aggregator

**Files:**
- Modify: `.github/workflows/pr.yml` (add a final job after all others)

- [ ] **Step 1: Add the aggregator job**

Append as the LAST job under `jobs:`:

```yaml
  # Single required status check. Branch protection requires ONLY this job.
  # It runs even when upstream jobs fail/skip (`!cancelled()`), and computes
  # the verdict explicitly so a `skipped` job (docs-only) cannot silently pass
  # — closing the Phase 1 skip-success class. Skipped on draft PRs (which are
  # unmergeable); re-runs for real on ready_for_review.
  ci-required:
    needs: [changes, policy, brand-check, verify, e2e, migrations]
    if: ${{ !cancelled() && (github.event_name != 'pull_request' || !github.event.pull_request.draft) }}
    runs-on: ubuntu-latest
    timeout-minutes: 2
    steps:
      - name: Evaluate required gate
        env:
          R_CHANGES: ${{ needs.changes.result }}
          R_POLICY: ${{ needs.policy.result }}
          R_BRAND: ${{ needs['brand-check'].result }}
          R_VERIFY: ${{ needs.verify.result }}
          R_E2E: ${{ needs.e2e.result }}
          R_MIGRATIONS: ${{ needs.migrations.result }}
        run: |
          echo "results: changes=$R_CHANGES policy=$R_POLICY brand-check=$R_BRAND verify=$R_VERIFY e2e=$R_E2E migrations=$R_MIGRATIONS"
          fail=0
          # The detector must have succeeded (it always runs when this gate runs).
          if [ "$R_CHANGES" != "success" ]; then
            echo "::error::changes detector did not succeed: $R_CHANGES"
            fail=1
          fi
          # Any required job that actually FAILED or was CANCELLED fails the gate.
          # 'skipped' is allowed (docs-only PR legitimately skips the heavy suite).
          for r in "$R_POLICY" "$R_BRAND" "$R_VERIFY" "$R_E2E" "$R_MIGRATIONS"; do
            case "$r" in
              failure|cancelled)
                echo "::error::a required job reported: $r"
                fail=1
                ;;
            esac
          done
          if [ "$fail" = "0" ]; then
            echo "ci-required: PASS (skipped heavy jobs allowed for docs-only changes)"
          fi
          exit $fail
```
